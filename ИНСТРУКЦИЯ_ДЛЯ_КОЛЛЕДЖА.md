# 🎓 Краткая инструкция по запуску проекта на компьютере в колледже

Эта памятка поможет быстро развернуть и запустить систему **PrintFarm 3D** в аудитории перед преподавателем за 1–2 минуты.

---

## ⚡ Способ 1: Запуск через батник (в 1 клик)

Самый быстрый и автоматический способ.

1. Скопируйте папку проекта с флешки на Рабочий стол компьютера колледжа (или распакуйте архив `print-farm-crm.zip`).
2. Запустите файл **`start.bat`** (двойным кликом).
3. **Что скрипт сделает автоматически:**
   * Найдёт и запустит локальную службу PostgreSQL (поддерживаются версии 17, 16, 15, 14).
   * Проверит наличие библиотек Python и, если их нет, сам установит: `pip install -r requirements.txt`.
   * Проверит подключение к базе (в `db.py` встроен умный перебор стандартных паролей `1234`, `postgres`, `12345`, `root`, `admin`).
   * Если база чистая — сам создаст таблицы и загрузит демонстрационные данные (`python db.py`).
   * Запустит сервер и **автоматически откроет браузер** на адресе `http://localhost:5003`.

---

## 💻 Способ 2: Запуск вручную в терминале VS Code

Если преподаватель просит показать код и запустить проект через редактор:

1. Откройте папку `print-farm-crm` в **VS Code** (`Файл` ➔ `Открыть папку...`).
2. Откройте встроенный терминал (`Ctrl + ~` или меню `Терминал` ➔ `Создать терминал`).
3. Выполните по очереди 3 простые команды:

```bash
# Шаг 1. Установка зависимостей (Flask, psycopg2, OpenPyXL и др.)
pip install -r requirements.txt

# Шаг 2. Создание схемы базы данных и заполнение чистыми данными
python db.py

# Шаг 3. Запуск веб-сервера
python app.py
```

4. Откройте браузер по адресу:  
   👉 **[http://localhost:5003](http://localhost:5003)**

## 🛠️ Возможные проблемы в аудитории и их быстрое решение

### 1. «Ошибка подключения к PostgreSQL / Password authentication failed»
* В файле `db.py` уже встроен автоматический подбор стандартных паролей (`1234`, `postgres`, `root`, `admin`).
* Если на ПК колледжа задан особый пароль суперпользователя: откройте файл **`db.py`**, найдите строку 11 и впишите пароль аудитории:
  ```python
  'password': os.environ.get('PGPASSWORD', 'ВАШ_ПАРОЛЬ_В_КОЛЛЕДЖЕ'),
  ```

### 2. «Служба PostgreSQL не запущена»
* Нажмите клавиши `Win + R`, введите `services.msc` и нажмите Enter.
* Найдите в списке службу `postgresql...` (например, `postgresql-x64-16` или `postgresql-x64-17`).
* Нажмите по ней правой кнопкой мыши ➔ **Запустить**.

### 3. «Порт 5003 уже занят»
* Откройте файл **`app.py`**, перейдите в самый конец файла и замените `port=5003` на `port=5004` или `port=8000`.
