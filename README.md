# 🖨️ PrintFarm 3D — Информационная система управления студией 3D-печати

Комплексная CRM / ERP-система и диспетчер производства для фермы 3D-принтеров и студии аддитивного производства. Разработана для автоматизации приёма заказов, диспетчеризации печати, складского учёта полимеров, расчёта себестоимости и финансовой аналитики.

---

## 🚀 Основные функциональные модули

### 1. 🏭 Диспетчерская и мониторинг цеха (Сводка студии)
* **Интерактивный дашборд**: мониторинг статуса принтеров в реальном времени (печать, простой, пауза, ошибка, оффлайн).
* **Телеметрия**: контроль температур сопла (Hotend) и печатного стола (Bed), расчёт прогресса печати и оставшегося времени в минутах.
* **3D-визуализация**: интерактивный предпросмотр моделей прямо в браузере (на базе **Three.js**).
* **Журнал событий (Аудит)**: фиксация всех ключевых действий сотрудников в системе.

### 2. 📋 Реестр заказов и клиентская база
* **Статусная воронка**: `Новый` ➔ `В производстве` ➔ `Готов к выдаче` ➔ `Выдан` (или `Отменён`).
* **Экономический калькулятор**: автоматический расчёт плановой себестоимости по весу деталей и машинному времени, расчёт рекомендуемой цены, чистой прибыли и маржинальности.
* **Печатные формы и наряды с QR-кодом**: генерация готового к печати технологического наряда и маркировочной этикетки на коробку с динамическим QR-кодом.
* **Клиентский трекер**: генерация уникальной защищённой ссылки для клиента (отслеживание этапов готовности деталей без авторизации в системе).
* **Email-оповещения**: автоматическая отправка клиенту стильного HTML-письма со ссылкой на трекер при создании и готовности заказа, а также кнопка повторной отправки.
* **Управление контрагентами**: быстрый справочник клиентов с мгновенным поиском, форматированием номеров телефонов и архивацией.

### 3. 📦 Складской учёт и прайс-лист материалов
* **Учёт катушек филамента**: хранение по материалам (PLA, PETG, ABS, ASA, PA-CF, PC, TPU, PLA-CF, PETG-CF), заводам-изготовителям, цветам и весу.
* **Автоматическая синхронизация с Google Таблицами**: умный импорт актуальных цен филаментов по открытой ссылке или CSV-файлу с сопоставлением по бренду и полимеру.
* **Каталог 3D-изделий**: справочник типовых моделей с привязкой артикулов (SKU), веса, времени печати и цены.

### 4. ⚙️ Инженерный симулятор производства
* Встроенный фоновый симулятор печати в реальном времени: принтеры с активными заданиями автоматически нагреваются, прогревают стол, инкрементируют процент готовности (динамический интервал 20–30 с), списывают граммы филамента со склада и завершают заказы.
* Имитация технологического брака с автоматической фиксацией перерасхода полимеров.

### 5. 📊 Аналитика производства и финансовый аудит
* **Ключевые метрики**: суммарная выручка, себестоимость выполненных партий, чистая прибыль, средняя рентабельность, масса переработанных пластиков и процент брака.
* **Экспорт отчётов в Excel (`.xlsx`)**: выгрузка сводного финансового аудита в формате электронных таблиц с разбивкой по заказам, материалам и статьям расходов (на базе **OpenPyXL**).

### 6. 👥 Ролевая модель доступа (RBAC)
* **Администратор (`admin`)**: полный доступ ко всем разделам, управлению пользователями, системным логам и удалению записей.
* **Менеджер (`manager`)**: оформление заказов, ведение клиентов, складской учёт, отчёты и аналитика.
* **Оператор 3D-печати (`operator`)**: доступ к дашборду цеха, управлению принтерами, очереди печати и оприходованию катушек на складе.

## 🛠️ Технологический стек

* **Бэкенд**: Python 3.12, Flask, Werkzeug, psycopg2-binary
* **База данных**: PostgreSQL 15+ / 17
* **Фронтенд**: HTML5, CSS3, JavaScript (ES6+), Bootstrap 5.3 (Dark/Light темы), Bootstrap Icons
* **Визуализация и графики**: Three.js (3D-рендеринг моделей), Chart.js (аналитические графики)
* **Отчётность**: OpenPyXL (генерация файлов `.xlsx`)
* **Сетевой стек / Интеграции**: Google Sheets CSV API, SMTP-сервис отправки уведомлений

## 📦 Быстрый старт и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/a9ua3rr0r/print-farm-crm.git
cd print-farm-crm
```

### 2. Создание и активация виртуального окружения
```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка базы данных PostgreSQL
Убедитесь, что сервер PostgreSQL запущен. Создайте базу данных `printfarm_db`:
```sql
CREATE DATABASE printfarm_db;
```

При необходимости настройте параметры подключения в файле `db.py` (по умолчанию: `localhost:5432`, пользователь `postgres`, пароль `postgres`).

Инициализируйте таблицы и демонстрационные данные:
```bash
python db.py
```

### 5. Запуск веб-приложения
```bash
python app.py
```

Приложение будет доступно в браузере по адресу:
👉 **[http://localhost:5003](http://localhost:5003)**

## 📂 Структура проекта

```text
print-farm-crm/
├── app.py                # Основной сервер Flask: маршрутизация, бизнес-логика, API

├── simulator.py          # Фоновый симулятор физической 3D-печати в реальном времени
├── schema.sql            # Исходная SQL-схема таблиц базы данных
├── requirements.txt      # Список зависимостей Python
├── static/
│   ├── css/style.css     # Кастомные стили, Glassmorphism-дизайн, тёмная и светлая темы
│   └── js/app.js         # Клиентская логика, таймеры, автообновление дашборда
└── templates/            # Jinja2 HTML-шаблоны страниц
    ├── base.html         # Базовый макет с сайдбаром и навигацией
    ├── dashboard.html    # Сводка студии и мониторинг принтеров
    ├── orders.html       # Реестр заказов и справочник клиентов
    ├── warehouse.html    # Склад катушек и каталог изделий
    ├── queue.html        # Очередь и запуск заданий
    ├── analytics.html    # Финансовая аналитика и экспорт Excel
    ├── order_print.html  # Печатная форма наряда с QR-кодом
    ├── track.html        # Клиентский публичный трекер заказа
    ├── users.html        # Управление пользователями студии
    └── login.html        # Страница авторизации
```
